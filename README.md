# 📼 THE RECORDING 4.0 — THE HOUSE REMEMBERS

A dark, difficult Pygame horror game where the house remembers everything.

You explore an abandoned house, discover mysterious VHS tapes, solve puzzles, manage your flashlight battery, and try to survive whatever is following you.

## 👁️ Features

* 🏚️ Explore multiple rooms
* 📼 Collect and watch mysterious VHS tapes
* 🔦 Manage a limited flashlight battery
* ❤️ Health system with creature damage
* 🔴 Health bar shakes and flashes when you're hit
* 😨 Fear system that changes the horror events
* 👹 A creature that can appear and chase you
* ⚡ Fuse and basement puzzles
* 📺 VHS/TV glitch effects
* 🌑 Screen flashes, shaking, darkness, and other horror effects
* 🏆 Multiple endings
* 🔒 A hidden, extremely difficult ending for players who discover the right conditions

## 🎮 Controls

| Key       | Action                                  |
| --------- | --------------------------------------- |
| `W A S D` | Move                                    |
| `E`       | Interact                                |
| `F`       | Toggle flashlight                       |
| `ESC`     | Quit                                    |
| `SPACE`   | Continue / interact with certain events |

## ❤️ Survival

Your health is limited.

If the creature gets too close, you take damage. Getting hit causes the health bar to shake and flash red.

Your flashlight battery is also limited, so don't waste it.

The higher your **FEAR** gets, the more dangerous and unpredictable the house becomes.

## 📼 The VHS Tapes

The tapes are important to the story.

Finding and watching them can unlock new areas, events, clues, and endings.

But watching them may also make the house react...

## 👹 The Creature

The creature does not always appear when you expect it.

Sometimes the house is completely quiet.

Sometimes you might see something for only a moment.

And sometimes...

**it knows where you are.**

## 🏆 Endings

There are multiple endings depending on the choices you make and the conditions you meet.

Some endings are easier to discover.

Others are hidden behind very specific requirements.

There is also a secret ending that is intentionally **very difficult** to achieve.

## 💻 Requirements

* Python 3
* Pygame

Install Pygame with:

```bash
pip install pygame
```

Then run:

```bash
python main.py
```

## ⚠️ Difficulty

This game is intentionally challenging.

Don't expect everything to be obvious.

Pay attention to:

* VHS tapes
* Battery level
* Fear level
* Room changes
* Messages
* The creature
* Hidden clues

Sometimes the safest thing to do...

**is pay attention.**
